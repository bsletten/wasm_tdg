WebAssembly: The Definitive Guide

Live, runnable browser examples from the book — built by CI, served from GitHub Pages.

Every example below is compiled from source in the book's repository by a GitHub Actions workflow and published here. Nothing is pre-baked by hand: the .wasm you load is the output of wat2wasm, clang, emcc, rustc, asc or dotnet running in CI.

Many of these examples are deliberately minimal and report their results to the JavaScript console rather than the page — that is how they appear in the book. Open your developer tools before loading one marked console.
